Pesquisa e Testes de Software

Trabalho sobre testes de software realizado utilizando o site Savana como aplicação para os testes.

Parte 1 - Pesquisa

Testes de Software

São processos utilizados para verificar se um site ou aplicativo está funcionando corretamente antes de ser utilizado pelos usuários.

Testes Funcionais

Verificam se as funcionalidades do sistema estão funcionando conforme o esperado.

Exemplo: testar se o botão de login funciona.

Testes de Regressão

Verificam se alterações feitas no software não causaram problemas em funcionalidades que já funcionavam.

Exemplo: modificar o cadastro e testar novamente o login.

Testes Unitários

Testam pequenas partes do sistema separadamente.

Exemplo: testar uma função que verifica a senha.

Testes de Integração

Verificam se diferentes partes do sistema funcionam corretamente juntas.

Exemplo: verificar se um formulário envia dados corretamente para o banco de dados.

Teste Caixa-Preta

O sistema é testado sem analisar o código interno.

Exemplo: digitar uma senha errada e verificar se aparece uma mensagem de erro.

Teste Caixa-Branca

O teste é realizado analisando a estrutura interna e o código do sistema.

Exemplo: verificar se todas as condições de uma função foram executadas corretamente.

Parte 2 - Casos de Teste

A aplicação escolhida foi o site Savana. As funcionalidades testadas foram os links dos projetos no GitHub e o download do currículo.

CT01 - Acesso ao GitHub

Teste: clicar no botão de um projeto.

Resultado esperado: o usuário deve ser direcionado para o repositório no GitHub.

CT02 - Links dos Projetos

Teste: verificar os links dos projetos.

Resultado esperado: todos os links devem funcionar corretamente.

CT03 - Download do Currículo

Teste: clicar no botão para baixar o currículo.

Resultado esperado: o currículo deve ser baixado corretamente.

CT04 - Abertura do Currículo

Teste: abrir o currículo após o download.

Resultado esperado: o arquivo deve abrir normalmente.

Teste Resultado Obtido Status
CT01 O GitHub abriu corretamente. ✅ Aprovado
CT02 Todos os links funcionaram corretamente. ✅ Aprovado
CT03 O currículo foi baixado corretamente. ✅ Aprovado
CT04 O currículo abriu normalmente. ✅ Aprovado

Problemas Encontrados

Não foram encontrados problemas durante os testes. Todos os casos apresentaram os resultados esperados.

Conclusão

Após realizar os testes, consideramos que a aplicação está funcionando corretamente. Todos os quatro testes realizados foram aprovados e apresentaram os resultados esperados.
