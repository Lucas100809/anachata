PARTE 1

Pesquisa

Conheça alguns dos principais testes de software.

💻

Testes de Software

São processos utilizados para verificar se um sistema está funcionando corretamente antes de ser utilizado pelos usuários.

Exemplo: testar se um site funciona corretamente.

⚙️

Testes Funcionais

Verificam se as funcionalidades do sistema funcionam conforme os requisitos.

Exemplo: testar se o botão de login funciona.

🔄

Testes de Regressão

Verificam se mudanças feitas no sistema não causaram problemas em funcionalidades que já funcionavam corretamente.

Exemplo: modificar o cadastro e testar novamente o login.

🧩

Testes Unitários

Testam pequenas partes do sistema de forma isolada, como funções ou componentes.

Exemplo: testar uma função que verifica a senha.

🔗

Testes de Integração

Verificam se diferentes partes de uma aplicação conseguem funcionar corretamente juntas.

Exemplo: testar se um formulário envia dados corretamente.

⬛

Teste Caixa-Preta

O sistema é testado sem analisar o código interno, verificando apenas os resultados.

Exemplo: digitar uma senha errada e verificar a mensagem.

⬜

Teste Caixa-Branca

O teste é realizado analisando a estrutura interna e os caminhos do código.

Exemplo: verificar as condições de uma função.
